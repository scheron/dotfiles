# Review criteria

This skill exists to give one file a stable, installed path. It runs nothing.

The material is in [CRITERIA.md](CRITERIA.md), next to this file. Three seats
read it — `implement-review`, `final-review` and `ds-review` — and each is
handed the path by whoever dispatches it.

Everything else in this directory is that reference. There is no procedure here
to follow.
